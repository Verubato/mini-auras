# MiniAuras

Features:

- Create custom mini weak aura icon alerts with sound.
- Displays enemy CC on party/raid frames.
- Active cooldowns shown on party/raid frames.
- Show important and defensives on nameplates.
- Important/defensive spell icons on portraits.
- Enemy and ally kick timers.
- Party PvP trinkets.
- Notification of when your healer is in CC.
- Sound alerts of enemy spells.
- Supports many frame addons such as ElvUI, Danders Frames, Ellesmere Frames, etc.
- Available in 10 languages.

Any feedback is more than welcome.
